A **portfolio** is a named set of stocks. Here it is saved as a file in the `portfolios` folder, so it is there next
time you open the app (**File > Load Portfolio...**).

- **File > New Portfolio** creates one; rename it by double-clicking or pressing F2.
- Right-click it to **add stocks**, and right-click any stock to add it to another portfolio.
- Each stock keeps its own views and strategies.

Grouping stocks this way is the first step towards testing a strategy on a *whole* portfolio, not just one stock.
